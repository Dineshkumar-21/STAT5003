# STAT5003
This is the group project repository for STAT5003.

Stage One focuses on the planning and Exploratory Data Analysis (EDA) of the Global Terrorism Database (GTD), a research dataset maintained by the National Consortium for the Study of Terrorism and Responses to Terrorism (START) at the University of Maryland (START, 2022). Throughout this project, we will use and interpret the dataset responsibly and respectfully, acknowledging its sensitive nature and research purpose.

Stage Two focuses on developing, implementing, and evaluating the five proposed models using the insights and outcomes from Stage One.

The Global Terrorism Database (GTD) is not stored directly in this
repository because of its large file size.

Dataset:
Global Terrorism Database (GTD)
Maintained by START, University of Maryland.

Download the dataset from the official source and place the file
in this directory before running the analysis.
