Classifying fatality severity in recorded terrorist incidents

GROUP: W12G05

Research question: How accurately can recorded incident context classify GTD incidents in 2019–2020 into zero, 1–4 and 5+ fatalities when models are developed on 2012–2018 incidents?

1. Framing, motivation and dataset selection

Humanitarian analysts and public-health researchers need to understand variation in the consequences of recorded violence and the reliability of historical evidence. Communities affected by violence are harmed by misleading estimates of severity. This analysis can inform research prioritisation and the examination of reporting gaps by identifying which contextual patterns persist in later data and where classification errors remain substantial.

The unit is one recorded incident. The outcome uses nkill: zero, 1–4 or at least 5 deaths. These are transparent analytical bands, not an official GTD severity scale. The higher-count band preserves an adequately sized severe tail. GTD fatalities include victims and perpetrators (National Consortium for the Study of Terrorism and Responses to Terrorism [START], 2021). This is retrospective classification conditional on a recorded incident; it does not predict attack occurrence, civilian deaths or individual risk.

2. Consider and gather data

The dataset, ‘globalterrorismdb_0522dist.xlsx’, is the May 2022 distribution of the Global Terrorism Database (GTD)(https://www.start.umd.edu/data-tools/GTD), maintained by the National Consortium for the Study of Terrorism and Responses to Terrorism (START), University of Maryland (START, 2022). It contains incident-level descriptors and recorded fatality counts that directly support the research question on classifying fatality-severity bands. This is an external research dataset, not a built-in R dataset or a prohibited Kaggle topic. The project uses one source only and does not perform external data linkage. Therefore, integration is not claimed as a dataset characteristic.

4. Preprocessing and five-model plan

Predictor selection and leakage control

Planned predictors: country, region, primary attack category, primary weapon category, primary target category, year, month, latitude and longitude.

Excluded variables: recorded deaths, injuries, success, suicide, property damage, narrative text, perpetrator identities, event IDs and source text. Deaths define the outcome, while injuries, success and damage are recorded consequences of the same incident; including them could leak post-incident information into the classification task. Narratives, identities, IDs and source text are excluded because they are high-cardinality, retrospectively coded, identifying, or may contain direct outcome clues.

These descriptors are used for retrospective classification of recorded GTD incidents. Their availability before or during a real-world incident is not assumed. The project does not claim prospective operational prediction.

  1. Define the cohort and three response bands. Exclude missing or negative fatalities; never impute a target. Preserve genuine extreme values.
  2. Map categorical “Unknown” and blanks to “Missing”. Mark invalid coordinates and month outside 1–12 as missing. Learn numerical medians from the training partition and add missingness indicators.
  3. Replace month with sine/cosine to represent its cycle. Standardise numeric features using training means/standard deviations. Pool categorical levels occurring fewer than 100 times into “Other”; unseen levels map there too.
  4. Fit every transformation separately inside each temporal fold. Logistic regression, the decision tree and boosting use a one-hot design matrix (with dimensionality checked after training-only encoding); forest and naïve Bayes use factors. One-hot tree inputs avoid costly searches over many country-level partitions. PCA and synthetic oversampling are not planned.

make_features <- function(d) {
  x <- d[, c(cat_vars, 'iyear', 'latitude', 'longitude')]
  for (v in cat_vars) {
    x[[v]][is.na(x[[v]]) | x[[v]] == 'Unknown'] <- 'Missing'
  }
  x$latitude[!is.na(x$latitude) & abs(x$latitude)>90] <- NA_real_
  x$longitude[!is.na(x$longitude) & abs(x$longitude)>180] <- NA_real_
  month <- d$imonth
  month[!month %in% 1:12] <- NA_real_
  x$month_sin <- sin(2*pi*month/12)
  x$month_cos <- cos(2*pi*month/12)
  x
}

run_eda <- function(data_path) {
  message('Reading original Excel workbook in R ...')
  # Import as text to prevent type-guessing from discarding late non-numeric cells.
  raw <- as.data.frame(readxl::read_excel(data_path,col_types='text',na=''))
  blank <- vapply(raw,function(z)mean(is.na(z)),numeric(1))
  numeric_like <- vapply(raw,function(z) {
    z <- z[!is.na(z)]; length(z)>0 && all(!is.na(suppressWarnings(as.numeric(z))))
  },logical(1))
  audit <- list(rows=nrow(raw),columns=ncol(raw),numeric_like=sum(numeric_like),
    text_like=sum(!numeric_like),any_missing=sum(blank>0),blank=blank,
    duplicated_ids=sum(duplicated(raw$eventid)),duplicated_rows=sum(duplicated(raw)),
    source_mb=file.info(data_path)$size/1e6,memory_mb=as.numeric(object.size(raw))/1e6)
  for (v in names(raw)[numeric_like]) raw[[v]] <- as.numeric(raw[[v]])
  recent <- raw[raw$iyear>=2012 & raw$iyear<=2020,]
  audit$recent_n <- nrow(recent); audit$unknown_n <- sum(is.na(recent$nkill)|recent$nkill<0)
  miss_fields <- c('nkill','nwound','latitude','nperps','propvalue','ransomamt')
  missing_by_year <- sapply(miss_fields,function(v) {
    z <- recent[[v]]
    if (v %in% c('nperps','propvalue','ransomamt')) z[z %in% c(-9,-99)] <- NA
    tapply(is.na(z),recent$iyear,mean)*100
  })
  labelled <- recent[!is.na(recent$nkill)&recent$nkill>=0,]
  labelled$severity <- factor(ifelse(labelled$nkill==0,'0 deaths',
                     ifelse(labelled$nkill<5,'1-4 deaths','5+ deaths')),levels=classes)
  train <- labelled[labelled$iyear<=2018,]; test <- labelled[labelled$iyear>=2019,]
  audit$train_n <- nrow(train);audit$test_n <- nrow(test)
  audit$train_classes <- table(train$severity);audit$test_classes <- table(test$severity)
  audit$kill_summary <- c(mean=mean(train$nkill),median=median(train$nkill),
      quantile(train$nkill,c(.25,.75,.95,.99)),max=max(train$nkill))
  fence <- quantile(train$nkill,.75)+1.5*IQR(train$nkill)
  audit$outlier_fence <- unname(fence);audit$outlier_n <- sum(train$nkill>fence)
  ct <- table(train$attacktype1_txt,train$weaptype1_txt)
  audit$cramers_v <- sqrt(unname(suppressWarnings(chisq.test(ct))$statistic)/
                         (sum(ct)*min(nrow(ct)-1,ncol(ct)-1)))
  audit$rho <- cor(train$nkill,train$nwound,use='complete.obs',method='spearman')
  xx <- make_features(train)
  audit$missing_predictors <- sapply(xx,function(z)mean(is.na(z)|z=='Missing'))*100
  message('R audit complete: ',nrow(raw),' rows, ',ncol(raw),' columns.')
  eda <- train[,c('iyear','nkill','nwound','latitude','longitude',cat_vars)]
  result <- list(source_hash=digest::digest(file=data_path,algo='sha256'),
    audit=audit,eda=eda,missing_by_year=missing_by_year,
    generated=format(Sys.time(),tz='Australia/Sydney',usetz=TRUE))
  dir.create('results',showWarnings=FALSE)
  saveRDS(result,'results/eda_results.rds')
  writeLines(capture.output(sessionInfo()),'results/sessionInfo.txt')
  result
}

4.1 Evaluation plan and project timeline

Evaluation plan. Use macro-F1 as the primary metric because each severity band should contribute equally despite class imbalance. Also report per-class precision, recall and F1, balanced accuracy (mean recall), ordinary accuracy and a row-normalised confusion matrix. Recall for the 5+ band measures missed severe incidents; precision measures false alarms. Compare every model with a training-majority baseline. Select by mean temporal-validation macro-F1, refit on development data, and report a calendar-month block-bootstrap interval for the eventual test score. Weighted probabilities will require a development-only calibration check before probability interpretation.
